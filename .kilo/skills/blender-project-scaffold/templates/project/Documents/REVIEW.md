## Modes

- `Off` — no grader subagents; the controller self-reviews with `look`.
- `All` — every configured grader reviews each round in parallel.
- `Single` — only the grader named above reviews.

`Unset` is invalid once production starts. Select the mode in ordinary chat before the goal, and
record the exact user answer in the change log. The user may switch modes at any pause.
