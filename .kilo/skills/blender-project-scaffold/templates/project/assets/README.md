# Assets — {{PROJECT_NAME}}

| Folder | Use |
|---|---|
| `external/` | Third-party models, textures, HDRIs, audio, and libraries. Register in `Documents/ASSETS.md`. |
| `textures/` | Project-owned or project-modified textures. Keep originals and derivatives identifiable. |
| `hdri/` | Project-owned or licensed environment maps. |
| `models/` | Project-owned meshes and linked libraries. |
| `audio/` | sound effects, music, and voice assets. |

Use relative paths from the `.blend` file (`//assets/...`). Do not embed absolute paths.
