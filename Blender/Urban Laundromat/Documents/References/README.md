# References — Urban Laundromat

Collect visual references here: moodboards, screenshots, concept images, links, and notes about what to borrow from each. Use `blender_workflow {action:"intake"}` with `generated` metadata when an image-generation tool creates a reference; it copies the file, records the tool/model/prompt/seed, updates this index, and adds exact paths to the open change.

Use the reviewed `image_reference` operation to place a local reference image in the scene as a non-rendering viewport Empty. Use `image_texture` when the image is a material texture. Before shipping or embedding a third-party reference image, register it in `../ASSETS.md` and verify its licence permits the intended use and redistribution.

Record the confirmed requirements answer here first: exact paths, links, or `none`. A "no external assets" answer does not imply "no visual references"; ask explicitly.
