# References — CozyLaundromat

Confirmed reference answer: `Generate one` — one reference image will be generated after registration for visual direction. It is deferred until the project is registered, the initial scene is saved and checkpointed, and a bounded media change is open. The generated image is a reference input, not automatically a scene asset.

Generated concept images may be inspected, but they are not scene assets until brought in through `intake` with generated metadata. Use the reviewed `image_reference` operation to place a local reference image in the scene as a non-rendering viewport Empty. Use `image_texture` only when a local image is intended as a material texture.
